# Revised textbook layout

This release contains the conventional textbook redesign. The teaching content is unchanged from the first print edition.

- **Go edition:** 630 pages.
- **Python edition:** 619 pages.
- Times-style serif text, modest numbered headings and indented paragraphs.
- Plain tables, numbered monochrome code listings and numbered figures.
- Colour retained in the original diagrams.
- Simplified title pages and chapter introductions that flow into the lesson.
- All 27 chapters, 243 diagrams, 126 tables, 313 selected code blocks and 434 PDF bookmarks retained.

## Downloads

Download the full PDF for your preferred language, or its `Print-in-Parts.zip` bundle containing six smaller PDFs in reading order. Cover previews, a printing guide and SHA-256 checksums are also attached.

Print on A4 at 100% / Actual size, with automatic orientation and long-edge binding for two-sided printing. Wide diagrams use landscape pages.

The Go and Python editions select the corresponding website language tabs. Shared commands, SQL, configuration and standalone examples without an equivalent remain in their source languages.

The [original design remains available in v1.0.0](https://github.com/MagnusCarlsen26/backend-from-first-principles-pdf/releases/tag/v1.0.0).
